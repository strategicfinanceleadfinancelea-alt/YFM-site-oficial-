# YFM Finance

Site institucional da YFM Finance. Seu negócio em números. Suas decisões com estratégia.

Site estático: `index.html` + pastas `images/` e `video/`. Não precisa de build.

## Publicar no GitHub Pages
1. Crie um repositório e envie estes arquivos na raiz (o `index.html` precisa ficar na raiz).
2. Em **Settings > Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. Aguarde 1 a 2 minutos. O site abre em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
4. Envie uma mensagem de teste pelo formulário e confirme o e-mail de ativação do FormSubmit na caixa de entrada.
